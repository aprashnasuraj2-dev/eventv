## Architecture and counts
- 50 canonical URL groups: `https://aafnaipatro.com/events/<slug>/`
- Optional subdomain per topic: `https://<slug>.aafnaipatro.com/`; not created in DNS, and not an inherent SEO boost.
- 1,000 query/intent **hypotheses**: `research/search-intents-1000.csv` with URL ownership (20 per event).
- 200 event HTML pages: 50 hubs, 50 planning, 50 during, 50 post; 2 navigational HTML pages = **202 static HTML**.
- Four-stage URL group example: `/events/rugby-world-cup-2027/`, `/planning/`, `/during/`, `/after/`.
- Not all 20 intents should become separate pages; semantically similar questions belong on the same useful URL. `research/routes-200.csv` is the canonical ownership map.

## How to interpret priority
The categories are deliberately diversified across games and consumer software, official release events, commerce/holidays, calendar utilities and sports/travel. Provisional scores cannot establish actual competitor strength or traffic opportunity. Before releasing each cluster, use US/UK/CA/AU query-level SERP inspection, official event data, original functionality and GSC measured impressions. A topic can have huge demand but poor capturability.
