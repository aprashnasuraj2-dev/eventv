Buyer rule #1

Protocol support is not the same as a competition-ready fighting setup.

Valve’s Steam Input device documentation says major controller families are supported, and variants such as fighting game joysticks that use the same input protocol are covered under those base device families. But that does not certify your exact stick, leverless controller, button layout, simultaneous two-player behavior, menu navigation or button prompts inside a particular game.

Device detected ≠ correct layoutA fight stick may enumerate successfully while face-button labels or menu navigation remain awkward.
Local multiplayer ≠ Remote Play Together qualityRemote Play Together streams the host’s local multiplayer session; network quality and game behavior still matter.
Online multiplayer ≠ good fighting-game netcodeRollback/delay model, matchmaking regions, cross-play and spectator/replay tools are title-specific evidence.
Base roster ≠ complete-cost experienceCharacter passes, DLC fighters, stages and editions can materially change total cost.

Counterexample: a PlayStation-protocol arcade stick may be recognized through Steam Input, yet the game can still have incorrect prompts, poor menu navigation or local-player assignment problems. Hardware protocol support does not prove game-level UX.

Discount behavior

Remote Play Together

One copy can power a streamed local-versus session—but that is not native online multiplayer.

Valve says Remote Play Together allows Steam friends to join as though they were sitting at the same computer. Only the host needs to own and install the game. It is enabled automatically for games listed with Local Multiplayer, Local Co-op or Shared/Split Screen capability, though developers can adjust whether it is appropriate.

System counterexample: Remote Play Together can make a local-only fighter remotely playable without adding native matchmaking, server infrastructure, rollback netcode, cross-play or independent game ownership for the guest.

FAQ / verified Nov 6, 2026

Steam Fighting Fest 2027 questions

When is Steam Fighting Fest 2027?

Valve lists April 26 through May 3, 2027.

What time does Fighting Fest start?

The exact official clock is not verified here because Valve’s dedicated Fighting Fest 2027 documentation currently returns an error.

What kind of games qualify?

Valve says Fighting Games like those the FGC play—not merely any game containing combat. Generic themed-sale rules also require primary theme/mechanics to align with the event.

Are discounts mandatory?

No. Discounted released titles get the most prominent themed-sale treatment, but eligible free games, upcoming games and demos are welcome under the generic rules.

Does my arcade stick automatically work if Steam Input supports its protocol?

No. Protocol support is only one layer. Verify in-game buttons, prompts, menus and simultaneous local-player behavior with your exact device.

Does Remote Play Together mean the game has native online multiplayer?

No. It streams a local multiplayer session from the host. Only the host needs to own/install the game, but native matchmaking/netcode/cross-play are separate capabilities.

Will all fighters and DLC be discounted?

Unknown. Publishers choose title/package discounts; this page does not assume character passes, editions or DLC receive the same percentage as the base game.
