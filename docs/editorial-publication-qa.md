# Publication and static-page QA
**Noindex is intentionally on for all 202 generated HTML files.** This is a working content architecture, not 200 finished articles.

## Per URL quality gate
- [ ] Single differentiated primary user job; source-backed answer above fold
- [ ] Dates checked using the official organizer/authority on release day, showing unannounced when necessary
- [ ] Original research, comparison, calculation, accessibility detail, or functional tool—not boilerplate
- [ ] Five related intent hypotheses reviewed for real SERP capturability, expected zero-click competitors, overlapping pages
- [ ] Event trademark, clip, image, fixture-data and official feed licensing assessed
- [ ] Clear author/editor and timestamps, correction records, real-time claims only when monitored
- [ ] No unsupported earnings, pricing, transport, match or broadcaster claims
- [ ] Internal links and canonical tested; subdomain only with proper 301 strategy
- [ ] LCP/CLS/INP, mobile readability, accessible navigation verified
- [ ] Consent, cookies and advertising law reviewed for relevant visitors
- [ ] Adsterra placement behavior conforms to publisher rules, natural viewability and caps; never fake views, forced clicks, refresh or fake impressions
- [ ] Remove noindex only for approved routes; include only those in production sitemap
- [ ] Monitor GSC organic clicks by country/query; reconcile paid Adsterra impressions separately

## Minimum launch scope
Do not assume 50 topics should launch at once. Select 3–5 clusters with confirmed sources, original utility and demonstrably addressable questions. Publish 10–20 excellent pages, measure 30–60 days, then expand the reviewed cohort.

## Decision rule
Reject a page when the same intent is already answered by an existing EventV page, SERP direct answer or authoritative organizer with nothing material added.
