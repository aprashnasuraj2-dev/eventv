## 2027 developer baseline already confirmed
Apple Developer’s Sep 9, 2026 submission update says that starting April 2027:
- iOS/iPadOS uploads must use the iOS 27/iPadOS 27 SDK or later.
- tvOS uploads must use the tvOS 27 SDK or later.
- visionOS uploads must use the visionOS 27 SDK or later.
- watchOS uploads must use the watchOS 27 SDK or later.
No macOS SDK minimum is added to the page because it is not in the cited requirement list.

## Beta guidance used

- restoring to a prior release can require restoring from backup, and product-specific constraints exist.
